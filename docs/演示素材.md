# 演示素材

素材由 Android 15 / API 35、Pixel 6 配置模拟器运行 demo 构建生成。画面来自实际原生界面，不是设计稿。

## 隔离方式

- applicationId 为 cn.local.smsrelay.demo，与正式包隔离。
- demo manifest 移除 RECEIVE_SMS、SEND_SMS、READ_PHONE_STATE 和两个短信接收器。
- DemoActivity 仅写入虚构号码、说明性正文和模拟状态。
- 正式包开启截图保护；demo 通过资源覆盖关闭保护以供截图。
- 页面“短信桥 · 演示”、README 和正文均注明演示，模拟成功状态不表示真实发送。

## 复现

~~~sh
./gradlew assembleDemo
adb -s YOUR_EMULATOR install -r app/build/outputs/apk/demo/app-demo.apk
adb -s YOUR_EMULATOR shell am start -n cn.local.smsrelay.demo/cn.local.smsrelay.DemoActivity
~~~

使用独立模拟器。首页截图后切换全部模式、滚动到记录、点击记录查看正文。不要给 demo 增加短信权限或把它作为正式发行 APK。原始画面保存在 docs/images/。

overview.svg 为功能示意图；宣传文案见推广文案.md。
